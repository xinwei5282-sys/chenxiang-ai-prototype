# 佩戴养护二级页设计说明

## 结论

采用用户确认的 2 号方案「七则养护 · 编辑手册」。选定视觉稿为 `reference/care-editorial-manual-selected.png`，实现时以该图的信息层级、版式密度、色彩关系与视觉节奏为准，并复用现有小程序运行时、顶部导航和品牌视觉体系。

## 页面目标

- 把客户提供的横版养护说明转为适合手机纵向阅读的完整指南。
- 用户无需登录即可查看，并能快速理解佩戴、避水、清洁、存放、异常处理和日常盘护方法。
- 保持广垦沉香的暖米白纸张感、深绿色与铜棕色，呈现可信、克制的品牌说明页，不做营销页或卡片堆叠。

## 页面结构

### 1. 原生顶部导航

- 左侧返回按钮，居中标题 `佩戴养护`，右侧保留微信小程序胶囊区域。
- 延续现有 `TopBar`、安全区和 `FlowStack` 返回行为，不新增路由系统。

### 2. 编辑式题图

- 辅助标签：`广垦沉香 · 日常养护`。
- 主标题：`七件小事，让香气陪你更久`。
- 导语：说明沉香会吸收环境中的气味与水分，日常养护有助于保持原有香气与状态。
- 使用现有真实手串素材做左下局部题图，竹叶只作低对比背景装饰；图片不承担按钮或入口职责。

### 3. 七则连续正文

正文采用单一连续阅读面，不拆成独立卡片。每条由铜棕编号、黑色标题、灰绿色正文和细分割线组成：

1. `远离化学品`：洗涤剂、酒精、香水、花露水等可能影响表面与香气。
2. `避水与护肤品`：洗澡、洗手、喷香水、涂护肤品前取下手串，并说明遇水后可能出现的外观变化。
3. `避高温与油烟`：远离油烟、暖气、高温与长时间阳光直射。
4. `密封独立存放`：不佩戴时单独密封存放，避免串味。
5. `香气或表面状态变化后的处理`：保留客户提供的湿巾轻擦、阴干与养香说明；正式上线前由品牌内容负责人复核术语和操作安全性。
6. `轻柔清洁`：污渍使用稍湿软布轻擦，之后自然阴干。
7. `日常盘护`：棉手套或丝袜轻揉数分钟，再放入养香容器保养。

### 4. 养护提醒

- 页面末尾使用低强调浅色提示条，不做主按钮。
- 提醒内容聚焦天然材质、长期佩戴与温和养护，不使用医疗功效、确定性增值或夸大香气效果的表达。

## 视觉规范

- 背景：沿用现有暖米白纸色，不增加渐变、发光或重阴影。
- 主色：现有沉香深绿；编号与辅助标签使用现有铜棕色。
- 字体：导航、正文与操作使用系统中文字体；主标题可使用现有宋体体系。
- 正文建议 15–16px，行高 1.7–1.85；小字不得低于现有可读性基线。
- 页面左右内容边距与其他二级文章页一致；分割线使用现有 `--line` 色。
- 不使用卡片套卡片、宫格、徽章、胶囊标签组或额外营销 CTA。

## 交互与状态

- 页面为纵向可滚动文章，唯一主要交互是返回；正文不做折叠，避免用户遗漏客户要求的养护说明。
- 图片提供明确中文替代文本，不参与焦点顺序。
- 生产内容接口成功时展示 `title / content_version / updated_at / sections[]` 对应内容；接口失败且有缓存时继续展示缓存，并标注 `内容可能不是最新版本`，无缓存时显示明确错误与重试入口。
- 当前 React 需求原型继续使用静态内容，本次只验证成功阅读态，不新增内容接口、缓存或错误态模拟。
- iPhone 与 Pixel 10 均须保留顶部安全区、44px 以上返回热区和底部滚动余量。

## 实现边界

- 仅调整 `src/Prototype.tsx` 中 `careScreen` 的应用内容和 `src/prototype.css` 中养护页专属样式。
- 不修改受保护的移动运行时、顶部导航、设备框、键盘、通用样式或其他页面。
- 优先复用项目现有手串素材；若视觉稿中的竹叶背景没有合适的真实资产，则省略该装饰，不用 CSS 或手绘 SVG 仿造。

## 验收标准

- 七条客户内容均有对应条目，顺序正确，无缺项、重复或医疗功效表达。
- 首屏可看见标题、导语和至少第一条正文，页面向下滚动后可完整阅读全部七条及养护提醒。
- 视觉层级与选定稿一致：编辑式题图、连续编号正文、暖米白底、深绿主标题、铜棕编号。
- iPhone 与 Pixel 10 无文字溢出、裁切、顶部冲突或底部内容遮挡。
- 返回操作、滚动和浏览器级产品文档抽屉保持正常。
- `npm run check:runtime`、相关 Playwright 用例和 `npm run build` 通过；完成后对照选定视觉稿进行真实渲染检查。

- 内容接口、缓存和错误态的工程联调。
- 修改首页服务入口、其他二级页或小程序运行时。
