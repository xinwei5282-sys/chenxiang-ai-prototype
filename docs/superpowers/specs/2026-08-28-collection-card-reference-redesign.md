# 我的藏品参考图改版设计

## 目标

将首页“我的藏品”模块调整为用户提供参考图的横向档案卡样式，同时保留现有手串与认种树切换、对应档案打开、演示 PDF 下载和下载结果提示。

## 视觉结构

- 模块使用一张接近整屏宽度的白色圆角卡片，浅边框和轻阴影延续当前首页纸张质感。
- 卡片顶栏从左到右为：`我的藏品`、当前藏品的 `导出电子证书`、当前藏品的 `查看档案` 与右箭头。
- 主内容左侧为当前藏品方形缩略图；图片左右设置切换按钮，触控区域不小于 44px。
- 中间展示当前藏品名称、绿色认证状态、档案/认种编号及两项核心资料。
- 右侧使用低对比度圆形文字印记：手串显示 `香`，认种树显示 `树`。该印记只作装饰，不承担交互。
- 卡片底部显示两个圆点，当前藏品使用深绿色，非当前项使用浅灰色。

## 数据与交互

- 首页维护单一 `activeCollectibleIndex` 状态，默认显示海南琼南沉香手串。
- 左右按钮循环切换两项藏品；保留现有 `Carousel` 的横向滑动能力，并通过监听该模块现有滚动容器的位置同步当前索引，不修改受保护的移动运行时。
- 顶栏的证书下载和档案入口始终读取当前藏品，不能固定指向第一项。
- 点击档案入口继续进入现有手串档案或认种档案页面。
- 点击证书入口继续使用现有可用性检查、文件下载以及成功/失败提示。
- 不新增商城、后端、登录或新的二级页面。

## 代码边界

- 修改 `src/Prototype.tsx`：藏品模块状态、结构和当前项交互。
- 修改 `src/prototype.css`：卡片布局、字体、间距、认证徽标、印记和双设备适配。
- 修改 `tests/prototype-h5.spec.ts`：先增加当前项切换、链接跟随和参考图结构的失败测试，再实施代码。
- 不修改受保护移动运行时、设备外框、底部 Tab、档案页面和证书文件。

## 验收标准

- iPhone 与 Pixel 首页的“我的藏品”均呈现参考图的单卡结构，没有文字截断、元素重叠或横向溢出。
- 手串和认种树可通过左右按钮及横滑切换，圆点和正文同步更新。
- 证书下载与档案入口跟随当前藏品，原有成功、失败及返回行为不回退。
- 相关 Playwright 测试、移动运行时检查和生产构建通过。
- 真实渲染与参考图并排检查后，布局、层级、留白、圆角和颜色不存在 P0/P1/P2 差异。
