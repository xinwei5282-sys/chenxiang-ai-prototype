# “我的藏品”间距优化设计

## 背景

当前首页全局规则对 `.home-collection *` 强制设置最小 `12px` 字号，覆盖了藏品卡内部原本更细的层级；同时 iPhone 卡片使用 `88px` 图片、`40px` 印章和较窄的信息列，导致图片与文字视觉距离过短。

## 已选方案

只调整“我的藏品”，不改变首页其他模块：

1. 从首页全局最小字号规则中移除 `.home-collection *`，让藏品卡使用独立字号体系。
2. 明确藏品卡字号：标题 `14px`，操作 `11.5px`，藏品名 `12px`，状态 `9.5px`，元数据 `10px`。
3. iPhone 图片由 `88px` 调整为 `84px`，印章由 `40px` 调整为 `36px`；信息列增加 `8px` 左侧间距。
4. Pixel 图片由 `98px` 调整为 `92px`，印章由 `46px` 调整为 `40px`；保持更宽屏下的舒展比例。
5. 左右切换按钮继续保留 `44 × 44px` 触控区，不改变轮播、证书和档案交互。

## 备选方案与取舍

- 仅增加间距：仍受全局 `12px` 规则影响，信息区会继续拥挤，不采用。
- 全首页取消最小字号：会影响服务区、产业园和知识区，范围过大，不采用。
- 藏品模块定向解除覆盖并重新分配空间：影响最小、可独立验证，采用。

## 验收标准

- 图片与文字之间有清晰留白，不再贴靠。
- `CX-2018-072`、`TR-2026-018` 在 iPhone 和 Pixel 均完整显示。
- 藏品名称、认证状态、印章、左右箭头及分页点无裁切或重叠。
- 44px 切换热区、横滑归位、当前项证书/档案语义保持不变。
- `npm run check:runtime`、生产构建和藏品/证书专项测试通过。

## 范围边界

- 只编辑 `src/prototype.css` 与对应测试；如无需结构变化，不编辑 `src/Prototype.tsx`。
- 不修改首页服务区、产业园、知识区或受保护移动运行时。
