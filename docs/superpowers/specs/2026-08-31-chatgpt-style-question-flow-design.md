# 「问帖」ChatGPT 移动端风格双状态设计

## 背景与目标

当前「问帖」页仍偏传统卡片式聊天，与用户确认的 ChatGPT 移动端体验存在明显差异。本次改版将页面收敛为更安静、轻量、连续的文字对话界面：进入时先呈现明确的新对话入口，用户开始提问后切换为无结果卡的连续消息流。

本次只调整需求原型中的「问帖 / AI问事」页面，不接真实模型，也不改变首页、藏品、证书、养护和个人中心等其他业务页面。

## 已确认方向

- 每次进入「问帖」都创建一段新对话，不恢复上一次问答。
- 默认进入态采用已确认的方案 3：居中品牌入口、问题引导、三个快捷主题和文字输入框。
- 开始问答后采用已确认的方案 2：ChatGPT 式连续消息流，并用克制的广垦深绿强调结构标签。
- 默认态中央使用项目正式「广垦沉香」品牌 Logo。
- 页面只支持文字输入与发送，不支持图片、文件、相机、附件、语音或录音。

## 品牌与视觉真源

- Logo 使用真实资产：`public/assets/home-reference/guangken-chenxiang-logo.png`。
- Logo 只出现在默认新对话空状态，不在对话过程页重复出现。
- Logo 保持透明底、原始比例和原始绿色，不重绘、不变形、不加圆形底板或阴影。
- 页面以白色为主背景，正文近黑，辅助文案中灰；深绿只用于品牌 Logo、回答标签和少量交互强调。
- 不使用渐变、发光、科技蓝、大面积阴影、头像、在线状态或独立结果卡。

## 信息架构

### 1. 顶部导航

- 中间标题为 `AI问事`。
- 左侧保留返回按钮，返回进入前的页面。
- 右侧保留与视觉稿一致的轻量更多按钮；在本次需求原型中不承载核心流程，可保持视觉占位。
- 顶部导航固定，不能被消息滚动或模拟键盘遮挡。

### 2. 默认新对话态

- 主区域垂直居中展示正式「广垦沉香」Logo。
- 主标题：`今天想问什么？`
- 辅助文案：`先说说最近最挂心的事，我会再问两三句。`
- 展示三个轻量胶囊入口：`事业`、`感情`、`财运`。
- 点击快捷主题即直接发送对应主题，并进入对话过程态；快捷主题随后消失。
- 用户也可直接在底部输入任意文字并发送。
- 默认态不展示 AI 开场气泡，不展示历史消息。

### 3. 对话过程态

- 用户消息靠右，使用低饱和浅灰气泡，保持圆角但不使用深色大色块。
- AI 消息靠左，以无卡片或极轻量消息块呈现，正文保持连续阅读感。
- 不显示双方头像、名称、时间戳、在线状态或消息尾部装饰。
- 首次提问后，AI 先主动追问两到三个与问题相关的背景点，不立刻输出确定性结论。
- 用户补充后，AI 在同一消息流中继续回应；信息足够时给出结构化参考。
- 结构化回答使用行内深绿标签：`判断`、`提醒`、`建议`，标签之后直接接正文。
- 不生成独立「结果卡」、卦象编号、运势分数、命盘或确定性吉凶断言。
- 新消息出现后自动滚动到可读位置，最后一条消息不得被输入栏或键盘遮住。

### 4. 思考状态

- 用户发送后，在 AI 消息位置展示简洁的正在生成状态。
- 可使用三个小圆点或 `正在推演…`，但不使用独立 Loading 卡、全屏遮罩或头像动画。
- 思考期间禁止重复发送；回复出现后恢复输入能力。

### 5. 文字输入区

- 输入区固定在页面底部，并随模拟键盘抬升。
- 输入框占据主要宽度，提示文案为 `给 AI 问事发消息`。
- 右侧只保留圆形发送按钮。
- 空内容或仅空格时发送按钮不可用；发送后清空输入框。
- 输入区不得出现加号、回形针、图片、文件、相机、麦克风、语音波形、长按说话或录音权限入口。
- 输入区上方固定显示提示：`内容由 AI 生成，仅供娱乐参考`。

## 会话生命周期

- 从首页入口、底部「问帖」标签或其他页面跳转进入时，均初始化为默认新对话态。
- 离开「问帖」后，本次对话不作为下次进入的默认展示内容。
- 再次进入「问帖」时清空消息、输入内容、思考状态和快捷主题选择，重新展示 Logo 与三个快捷主题。
- 当前会话内允许连续追问；只要用户没有离开页面，就保持本次上下文。
- 本次原型不新增历史对话列表、继续上次对话、会话命名、收藏或分享能力。

## 原型对话逻辑

- 本次仍使用本地模拟回复，不接真实大模型。
- 快捷主题与自由文本共享同一发送流程。
- 第一轮 AI 回复应主动追问背景，示例结构：当前情况、持续时间、用户最在意的结果。
- 后续补充触发结构化参考，至少包含 `判断 / 提醒 / 建议` 三个段落。
- 回答语气克制，明确是传统文化角度的娱乐与自我反思参考，不作医疗、法律、财务或人生重大决策承诺。

## 响应式与可用性

- 适配当前原型覆盖的 iPhone 与 Pixel 移动视口。
- 可点击控件的有效触控区域不小于 44 × 44 CSS px。
- 正文字号和行高保证移动端连续阅读；辅助说明不得小到难以辨认。
- 输入框、发送按钮和快捷主题使用语义化按钮或输入元素，并提供可识别的可访问名称。
- 长消息允许自然换行；中文与英文、数字混排不能溢出视口。
- 模拟键盘出现时，顶部导航、最后一条消息和输入区均处于合理可见位置。

## 状态与异常边界

- 初始态：Logo、标题、辅助文案、三个快捷主题、免责声明和空输入框。
- 输入态：键盘开启，输入区抬升，正文区域同步缩短。
- 思考态：发送禁用，显示轻量生成提示。
- 连续对话态：用户可继续发送，AI 基于当前本地会话上下文返回模拟内容。
- 空输入：不创建消息，不进入思考态。
- 快速重复点击：不得产生重复用户消息或重复 AI 回复。
- 页面重新进入：始终回到初始态。

## 代码边界

- 主要修改 `src/Prototype.tsx` 中「问帖 / AI问事」页面组件、页面进入重置逻辑和本地模拟回复。
- 主要修改 `src/prototype.css` 中该页面的默认态、消息流、输入区、键盘避让和响应式样式。
- 更新 `tests/prototype-h5.spec.ts` 中初始态、会话重置、快捷主题、连续问答、输入行为和无上传/无语音控件相关断言。
- 使用现有正式 Logo 资产，不新增重绘版品牌文件。
- 不修改受保护运行时文件，不替换现有应用框架，不新增页面路由。

## 验收标准

- 每次从其他页面进入「问帖」，均看到全新的默认新对话态。
- 默认态中央使用正式「广垦沉香」Logo，比例和清晰度正确。
- 默认态包含 `今天想问什么？`、辅助文案与 `事业 / 感情 / 财运` 三个快捷主题。
- 发送自由文本或点击快捷主题后，页面切换为连续消息流，默认态内容消失。
- AI 至少先主动追问一次，再给出包含 `判断 / 提醒 / 建议` 的结构化参考。
- 对话过程不出现独立结果卡、头像、在线状态或历史会话入口。
- 页面只存在文字输入和发送；图片、文件、附件、相机、麦克风、语音与录音入口均不存在。
- `内容由 AI 生成，仅供娱乐参考` 在输入区上方持续可见。
- 输入、发送、思考状态、自动滚动、键盘避让与重新进入重置均可操作。
- iPhone 与 Pixel 的初始态、追问态和结构化回答态完成真实渲染检查。
- 最终视觉与已确认的两张参考稿进行同视口对照，`design-qa.md` 的最终结论为 `final result: passed`。
- 相关 Playwright 用例、`npm run check:runtime` 与 `npm run build` 通过；若全量测试存在已知无关失败，需明确记录，不得误报为本次通过。

## 非目标

- 不接入真实 ChatGPT、OpenAI API、命理模型或远程聊天服务。
- 不上传或存储用户图片、文件、音频和语音。
- 不新增历史会话、云同步、搜索、分享、收藏或会话管理。
- 不采集出生日期、出生时间、姓名、地理位置或其他敏感个人资料。
- 不调整「问帖」以外页面的内容结构和视觉方向。
