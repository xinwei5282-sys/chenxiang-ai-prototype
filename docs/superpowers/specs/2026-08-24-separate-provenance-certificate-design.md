# 首页农垦故事与证书溯源拆分设计

## 目标

消除首页“来自农垦的时间”和“证书与溯源”两个入口展示相同内容的问题，并移除不属于首页核心任务的“最近问帖”，让首页入口各自承担明确、互不重复的信息职责。

## 信息职责

- 农垦故事入口：回答“这串沉香来自怎样的产区与品牌”。展示琼南农垦产区、基地环境、长期种植与制作传承，不展示证书编号、质检状态或芯片节点。
- 证书与溯源入口：回答“这串产品如何被核验”。保留当前数字身份凭证、批次、制作、质检与芯片绑定时间线。
- 沉香知识入口：回答“沉香是什么、如何认识”。保持通用文化与品类知识，不承担品牌故事或单品认证。

## 首页调整

首页视觉语言、现有核心卡片尺寸、配色和一屏结构保持不变；删除“最近问帖”后，农垦故事与三项服务之间按设备高度自然分配留白，不新增替代模块。

- 删除首页“最近问帖”区块；历史记录统一保留在“我的 → 问帖记录”。
- 将“来自农垦的时间”改为“琼南农垦沉香”。
- 辅助文案改为“从一片林场，到一串沉香”。
- 右侧动作改为“了解农垦故事”。
- 点击后进入新的“农垦沉香”详情页，不再进入“证书与溯源”。
- “证书与溯源”三项功能入口及顶部手串身份入口继续进入现有证书页。

调整后的首页顺序为：`当前手串身份 → 开始问帖 → 琼南农垦沉香 → 证书/养护/知识 → 底部导航`。

## 农垦故事页

复用现有 `FlowScreen`、`TopBar` 和 `MobileScroll` 模式，不引入新路由库或新视觉系统。

页面内容顺序：

1. 标题：`从琼南农垦出发，认识这串沉香。`
2. 引导文案：说明海南琼南的林场环境、种植积累与沉香产业来源。
3. 三段信息：`产区环境`、`农垦积淀`、`从林场到手串`。
4. 轻量说明：品牌与产区故事用于介绍来源背景；本串真伪、批次和芯片信息请到“证书与溯源”查看。

页面不展示占卜、功效承诺、证书状态或重复时间线。

## 组件与数据流

- 新增 `farmStoryScreen(keyboard)`，返回独立 `FlowScreen`。
- 首页新增 `openFarmStory()`，通过 `flow.push(farmStoryScreen(keyboard))` 打开详情。
- 农垦故事入口只调用 `openFarmStory()`。
- `openProvenance()` 继续只服务顶部手串身份和“证书与溯源”。
- 删除首页 `home-recent-card` 及其点击处理；阅读历史继续由“我的”页面现有记录入口承载。
- 进入详情前继续复用 `prepareH5Transition(keyboard)`，保证键盘和焦点状态正确清理。

## 异常与边界

- 本次为本地需求原型，不新增网络请求、加载态、后端数据或持久化。
- 农垦故事使用固定演示内容；将来接入 CMS 时再替换为动态数据。
- 保持 iPhone 与 Pixel 一屏首页、不滚动首页、固定底部导航等现有约束。

## 验收标准

- 首页农垦入口文案与证书入口不再表达同一信息。
- 首页不再出现“最近问帖”和具体历史问题。
- “我的”页面继续提供问帖记录入口。
- 点击农垦入口进入标题为“农垦沉香”的独立页面。
- 点击“证书与溯源”仍进入现有证书与溯源页面。
- 两个详情页的标题、主体内容和信息职责明显不同。
- 返回、键盘隐藏、底部导航和授权流程无回归。
- iPhone 与 Pixel 首页仍保持一屏。

## 测试方案

- 先增加 Playwright 回归：点击农垦入口应进入“农垦沉香”，且页面不存在证书时间线。
- 继续验证“证书与溯源”入口进入原证书页并保留时间线。
- 验证首页不存在“最近问帖”，且“我的”仍存在问帖记录入口。
- 运行首页一屏布局测试、完整 Playwright 测试和 `npm run build`。
- 重新截取 iPhone 与 Pixel 首页并检查文案长度、对齐和一屏状态。
