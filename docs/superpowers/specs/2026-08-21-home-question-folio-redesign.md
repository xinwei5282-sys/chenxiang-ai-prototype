# AI 手串首页「问帖主场」改版设计

## 决策与目标

用户已选择方案 1「问帖主场」。本次不是继续润色现有首页，而是重排首屏结构，让消费者通过 NFC 打开页面后，在 2 秒内同时确认两件事：这是已核验的当前手串；可以立即为这串手串发起一次传统文化问帖。

首页仍承担数字身份入口，不让 NFC 直接跳入算命对话。`AI传统文化解读` 的业务名称保留，但视觉主标题改为更有产品感的 `为本串问一帖`，点击后进入已经完成的「沉香问帖」对话 Agent。

## 设计命题

通过「产品身份舞台 → 核验凭据 → 问帖题签 → 档案索引」的纵向结构，让用户先认串、再问事，整体呈现广垦沉香的东方档案气质，而不是功能菜单或通用 AI 首页。

## 首屏结构

### 1. 品牌与产品身份舞台

- 保留广垦沉香品牌标识、产品图片、编号 `CX-2018-072`。
- 品牌栏与大图合并成连续的深绿/暖木视觉舞台，弱化当前上下切成两块的拼接感。
- 图片高度从当前接近半屏缩减到约 34%–38%，让主入口能在不滚动时完整出现。
- 编号与 `数字身份已核验` 形成一条身份凭据，不再占用独立的大块白色说明区。

### 2. 问帖主入口

- 在首屏下半部放置唯一主操作 `为本串问一帖`。
- 副文案为 `说出此刻最挂心的事，我会先问清，再为你解读。`
- 保留小标签 `AI传统文化解读`，满足需求与对外表述，但不让“AI”成为第一视觉焦点。
- 使用横向题签/折页式构图、铜棕边线和明确箭头；不使用大圆角、渐变、玻璃或悬浮阴影。
- 整个题签为可点击区域，最小高度 88px，按下反馈明确。

### 3. 身份信息与次级索引

- `2018 / 海南琼南 / 清甜木香` 压缩为题签上方的一行产品注记，不再保留三个等权图标卡。
- `查看证书与溯源` 降为档案编号式次入口，但仍高于养护和知识。
- `佩戴养护`、`AI沉香知识`、`问问香文化顾问` 合并为底部两行档案索引，使用细线分隔，不做四宫格卡片。

## 视觉与文字规范

- 主色：沉香绿 `#0c3628`；纸色：暖米白；强调：铜棕。
- 标题与题签使用宋体；长正文使用项目现有可读字体策略。
- 正文不小于 14px，关键操作文案 18–22px；辅助标签不低于 10px，并保持足够对比度。
- 所有可点目标至少 44px；主问帖入口位于拇指易达区。
- 页面最多两种容器：产品舞台和问帖题签。其余信息直接用基线、编号与分隔线组织。

## 交互与状态

- 点击问帖题签时先收起模拟键盘，再通过现有 `FlowStack` 进入「沉香问帖」。
- 点击证书、养护、知识和顾问入口继续复用现有流程，不新增路由。
- 按钮支持键盘焦点与按下状态；不得破坏设备选择器、状态栏、Home 指示条和 Android 安全区。

## 修改边界

- 仅修改 `src/Prototype.tsx`、`src/prototype.css` 和对应测试。
- 不修改受保护的移动端运行时文件。
- 不新增图片资产；继续使用现有真实手串图片和广垦标识。

## 验收标准

- iPhone 与 Pixel 10 首屏无需滚动即可看到完整的 `为本串问一帖` 主入口。
- 问帖入口在视觉面积、对比和位置上明显高于证书及其他功能。
- 首页不再呈现三个元数据等权卡片、双列功能宫格或通用 AI 功能列表感。
- 点击主入口能进入「沉香问帖」，Agent 追问与解读流程保持通过。
- 真实尺寸完成至少两轮截图复核，视觉评分达到 90 分以上。
- Playwright 全量测试、`npm run check:runtime`、生产构建和 Sites worker 测试全部通过。
