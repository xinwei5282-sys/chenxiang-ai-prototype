# AI 手串微信小程序 UI 改版设计

## 已确认方向

用户选择可视化方案 3「随身香事」。本次把现有需求原型从“博物馆档案 H5”调整为“长期可使用的微信小程序产品”：保留沉香品牌的温润感，但去掉题签、英文编号、密集细线和概念化 AI 装饰。

当前交付仍是 React 需求原型，用于验证小程序的信息结构、视觉和交互；不在本次范围内迁移为 WXML/WXSS 或接入微信登录、支付、订阅消息等真实能力。

## 目标与用户

- 目标用户：购买或持有广垦沉香手串、通过 NFC 或扫码进入小程序的消费者。
- 第一任务：确认当前手串身份，并直接发起一次传统文化问帖。
- 长期任务：查看最近问帖、管理当前手串、查看证书与养护信息。
- 成功标准：首屏 2 秒内理解“这是我的手串”和“可以开始问帖”；界面看起来像真实微信小程序，而不是 AI 生成的文化概念稿。

## 设计命题

通过「当前手串 → 今天想问什么 → 最近问帖 → 三栏导航」的日常产品结构，让传统文化能力退到交互背后，让用户感知的是一个温润、可信、可以反复使用的沉香小程序。

## 信息架构

### 首页

1. 小程序导航栏：标题 `我的沉香`，右侧保留微信胶囊安全区。
2. 当前手串：真实产品缩略图、名称、编号、年份、产区与香韵；`数字身份已核验`作为轻状态，不再做大标题。
3. 问帖主操作：`今天，想问什么？` + `开始一次问帖`。不出现头像、在线状态、机器人图标或 AI 渐变。
4. 最近问帖：展示一条真实模拟记录 `新的合作是否适合推进？ / 三天前 · 风山渐`，点击进入问帖上下文。
5. 服务列表：证书与溯源、佩戴养护、沉香知识，使用普通列表行，不使用功能卡片宫格。
6. 底部三栏：`首页 / 问帖 / 我的`。首页高亮；点击问帖进入对话页，点击我的进入手串与档案页。

### 问帖对话页

1. 使用小程序标准顶部导航：返回、`沉香问帖`、右侧微信胶囊安全区。
2. 顶部只保留一条紧凑的当前手串身份行，不再使用大面积深绿档案带。
3. 对话采用“连续记录”而非聊天气泡：以 `你`、`解读`为短标签，用间距和浅色底区分，不使用圆头像、在线绿点和左右气泡。
4. 解读结果只保留一次明确结论和一次行动建议，不嵌套卡片。
5. 底部输入区遵循现有键盘和安全区逻辑；正文 15–16px，操作区不小于 48px。
6. 对话页是专注任务页，隐藏底部 Tab；返回后回到首页或问帖入口。

### 我的

1. 展示已绑定手串与数字身份状态。
2. 提供 `证书与溯源 / 佩戴养护 / 关于传统文化解读` 三个普通列表入口。
3. 不新增登录、积分、会员、商城或设置等未确认功能。

## 视觉系统

- 主色：沉香绿，用于主按钮、选中态和身份状态；不大面积铺满页面。
- 背景：带暖灰的米白，不使用纸张纹理、玻璃、光晕、渐变或仿古边框。
- 强调色：木棕，只用于产品信息与次级提示。
- 字体：小程序界面与正文使用系统黑体；产品名、问帖标题可有限使用宋体。每屏最多两套字体。
- 圆角：只用于主按钮、产品缩略图和必要的轻容器，统一 10–14px；列表行与对话记录不做卡片。
- 图标：使用同一套线性图标；不使用 Unicode 符号、emoji 或自绘装饰图标。
- 动效：只保留页面进入、按下反馈和 Agent 思考状态；不使用浮动、弹跳和炫技转场。

## 删除与保留

### 删除

- 首页的 `CURRENT OBJECT`、`PRIVATE READING`、`壹 / 身份档案`等装饰标签。
- 大面积档案纸、题签边框、纵排批注和过多横线。
- AI 头像、在线状态、发光、渐变、卡片墙和嵌套结果卡。
- 为了填满页面而新增的营销文案与无功能装饰。

### 保留

- 广垦沉香品牌、真实手串图片和编号 `CX-2018-072`。
- 2018、海南琼南、清甜木香、数字身份已核验。
- `AI传统文化解读`业务名称，但在用户界面优先使用 `问帖`。
- Agent 主动追问、连续回答、娱乐与自我反思免责声明。
- 证书、养护、知识和香文化顾问的现有流程。

## 交互与异常状态

- NFC/扫码仍先进入当前手串首页，不直接开始问帖。
- 页面切换前继续释放焦点并收起模拟键盘。
- 无最近问帖时显示一句引导和 `开始第一次问帖`，不展示空白卡片。
- Agent 思考中禁用发送按钮，并显示克制的文字状态。
- 模拟回复失败时保留用户输入，显示 `暂时没有解读出来，请再试一次`和重试操作；本原型至少保留布局位置与文案规范。
- 免责声明固定出现在问帖页面内容区，不遮挡输入框。

## 修改边界

- 产品 UI 仅修改 `src/Prototype.tsx`、`src/prototype.css` 和对应测试。
- 不修改受保护的手机设备运行时、状态栏、键盘、设备资源与构建配置。
- 通过应用内自定义导航模拟微信小程序标题栏和胶囊安全区；不把系统状态栏写进产品页面。

## 验收标准

- 首页在 iPhone 与 Pixel 10 首屏完整显示当前手串、主问帖操作和底部三栏。
- 主操作触控区域至少 48px，正文不小于 15px；顶部导航不与状态栏或胶囊区冲突。
- 首页、问帖、我的三个导航动作可用；问帖主动追问与解读流程保持可用。
- 页面不出现头像在线点、左右聊天气泡、英文档案标签、重复圆角卡片和嵌套结果容器。
- 完成至少两轮真实截图复核，视觉评分达到 90 分以上。
- Playwright 全量测试、运行时完整性检查、生产构建和 Sites worker 测试全部通过。
