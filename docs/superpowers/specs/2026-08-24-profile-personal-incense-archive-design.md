# “我的”页个人香事档案改版设计

## 背景

当前“我的”页依次展示授权行、大标题、统计信息、两组卡片和底部说明，分隔层级较多，页面显得松散，也没有延续首页的米白、深绿和暖金视觉体系。

本次改版只调整“我的”根页面。首页、问帖 Agent、证书、养护、知识及农垦故事页面不在本次视觉改动范围内。

## 设计目标

- 让“问帖记录”和“我的手串”成为页面主任务。
- 将微信授权状态融入同一张身份卡，避免出现割裂的独立登录模块。
- 延续首页的暖东方材质感，同时保留真实微信小程序的紧凑和易用性。
- 在 iPhone 与 Pixel 预览设备上，使主要内容完整位于底部导航上方，默认不依赖滚动。
- 保留现有路由、授权状态和登录后继续问帖的行为。

## 已选方向

采用 C「个人香事档案」。顶部使用一张米白身份卡形成品牌记忆，下面用深绿双入口集中承载记录与管理，最后以轻量分割线清单承载使用帮助。

虽然方向 C 的品牌感更强，但身份卡不得压过核心入口：卡片高度需受控，不使用大面积图片、装饰纹样、渐变、发光或额外统计模块。

## 页面结构

### 1. 小程序标题栏

- 保留现有根页面标题“我的”和右侧小程序胶囊。
- 不改变受保护的设备状态栏、底部安全区或小程序运行时结构。

### 2. 个人香事档案卡

- 使用米白表面、细边框和 10–12px 圆角。
- 标题“个人香事档案”使用有限的宋体强调，其余文字使用系统字体。
- 未登录状态：展示简短说明“登录后，保存每一次识香与问帖”及“微信授权登录”按钮。
- 已登录状态：在同一卡片、同一位置切换为微信用户信息和“已登录”状态；不增加第二张卡，不改变页面整体高度。
- 授权按钮保持至少 44px 的可点击高度。

### 3. 记录与管理双入口

- “问帖记录”和“我的手串”在同一深绿色容器内并列展示，作为页面视觉与任务中心。
- 每个入口整格可点击，标题清晰，副信息分别使用真实模拟数据：
  - 问帖记录：`1 条 · 最近三天前`
  - 我的手串：`已识别 1 串`
- 图标使用项目现有图标库，保持统一线性风格，不使用图片切片。
- 两个入口均满足至少 44px 的触控热区。

### 4. 使用帮助清单

- 保留“芯片识别说明”和“关于传统文化解读”。
- 取消独立圆角外卡片，只通过小标题、行间距和细分割线组织。
- 副文案保持简短：
  - 芯片识别说明：`轻触 NFC，即可识别对应手串`
  - 关于传统文化解读：`仅供娱乐与自我反思参考`
- 图标使用现有图标库，颜色和尺寸与首页服务入口保持同源。

### 5. 删除项

- 删除当前“你的香事，都在这里”大标题。
- 删除独立的“已识别 1 串 / 1 条问帖记录”统计区，数据改由两个核心入口承载。
- 删除重复的“我的内容”等层级标题。
- 删除底部“无需注册账号”的冗长脚注；必要的登录说明放在身份卡内表达。

## 视觉规范

- 背景：沿用首页暖米白页面底色。
- 主色：沿用首页深绿；身份卡文字使用深绿和墨色。
- 强调色：暖金只用于小标签、边界或极少量状态强调。
- 圆角：统一为 10–12px，不叠加多层卡片。
- 字体：系统字体为主，宋体只用于“个人香事档案”标题。
- 图标：全部使用现有图标库；不使用切图、Emoji、手绘 SVG 或新增图片资源。
- 阴影：不使用明显浮层阴影；需要层次时优先通过边框、留白和底色区分。

## 交互与状态

- 点击“微信授权登录”后，继续使用现有共享授权状态，在身份卡内切换为已登录状态。
- 点击“问帖记录”：
  - 未登录时打开现有手机范围授权面板。
  - 授权后直接进入现有问帖流程。
  - 已登录时直接进入现有问帖流程。
- 点击“我的手串”直接进入现有证书/手串详情页面，不新增登录门槛。
- 帮助清单本次维持信息展示，不新增二级路由。
- 底部“首页 / 问帖 / 我的”导航行为保持不变。

## 代码边界

- 只修改 `src/Prototype.tsx` 中 Profile 页面拥有的结构，以及 `src/prototype.css` 中 Profile 页面样式。
- 更新与 Profile 相关的测试；不修改受保护运行时文件。
- 复用现有授权上下文、`ServiceRow` 或现有图标组件；如果现有结构妨碍布局，可在 `Prototype.tsx` 内增加 Profile 专用的小组件，但不进行无关重构。

## 异常与边界状态

- 授权状态切换后不得产生布局跳动、内容溢出或重复卡片。
- 文案在窄屏下不得截断核心标题；副信息允许单行省略，但主要按钮文字必须完整。
- iPhone 与 Pixel 的状态栏、安全区和底部导航不得遮挡内容。
- 授权面板取消后保留在当前页面，不误进入问帖。

## 验收标准

- “我的”页首屏只出现一张身份卡、一组双入口和一组帮助清单，视觉上形成连续的三段结构。
- “问帖记录”和“我的手串”比帮助项更醒目，且整格可点击。
- 未登录和已登录状态均位于同一身份卡内。
- 页面不再出现“大标题 + 独立统计区 + 多组外卡片”的散乱结构。
- 页面视觉与首页共享米白、深绿、暖金、系统字体和有限宋体强调。
- 现有授权后继续问帖、手串详情跳转和底部导航行为不回归。
- 相关自动化测试通过，`npm run check:runtime` 和 `npm run build` 通过。
- 使用真实浏览器分别检查 iPhone 和 Pixel 的未登录、已登录状态截图，并确认无裁切、遮挡、异常间距和错误圆角。

## 非目标

- 不实现真实微信授权、后端账号绑定或云端同步。
- 不新增问帖记录列表页、帮助详情页或手串管理功能。
- 不调整首页、问帖 Agent 或现有二级页面的视觉结构。
- 不生成或引入新的位图素材。
