# 「我的」单列账户清单设计

## 背景与目标

当前「我的」页使用米白身份卡、深绿双入口和独立帮助分组，虽然功能完整，但容器较多、视觉重量偏大。本次按用户确认的方案 1 重构为更轻、更直接的单列账户清单：先识别账号状态，再按使用频率进入问帖记录、本串证书和帮助内容。

本次只调整「我的」根页面的结构与样式，不改动首页、商城占位、问帖流程和二级页面内容。

## 视觉真源

- 已确认视觉稿：`reference/profile-simple-list-selected.png`。
- 视觉稿只定义 app-owned 内容的布局、密度、层级和色彩；设备边框、状态栏、小程序胶囊、底部安全区仍由受保护运行时负责。
- 视觉稿中的灰色文字条是构图占位，最终页面必须使用真实中文文案与现有图标库。

## 信息架构

### 账号授权 Banner

- 页面顶部使用独立产品图 Banner，真实资产为 `public/assets/profile/profile-account-banner.png`，用沉香手串建立第一视觉焦点并与下方列表拉开层级。
- Banner 背景不得包含文字、Logo 或按钮；账号文案、状态和授权按钮必须使用真实 HTML 排版并保持清晰可点。
- Banner 从设备顶部状态/电量区域后方开始通铺，左右贴满屏幕；小程序标题与胶囊浮在 Banner 上。
- 头像、账号文案和 `微信授权登录` 位于同一横排，登录或状态控件右对齐；下方功能列表仍保持 18px 安全边距。
- 账号横排位于 Banner 上半部；点击 `微信授权登录` 先打开手机内微信授权弹层，确认后才切换登录状态。
- Banner 下半部展示两个可点击数据入口：`1 条 / 问帖记录` 与 `1 串 / 证书数量`，分别进入历史记录和本串证书。
- Banner 已承载记录与证书后，页面下方删除重复的 `问帖记录` 与 `本串证书` 行，只保留一个芯片说明入口。
- 未授权时展示默认头像、`微信账号`、`授权后同步香事记录` 和 `微信授权登录`。
- 已授权时在同一位置展示默认头像、`微信用户`、`已完成微信授权` 和 `已登录`。
- 登录按钮保持次要操作样式，触控区域不小于 44 × 44 CSS px。

### Banner 数据入口与帮助清单

- 问帖记录和证书数量作为两个等宽数据入口放在 Banner 下半部，整格可点击并保留原有跳转。
- 两个数据入口不使用白色或品牌色块级底色，不使用外框和圆角；仅以中间一条浅色竖线划分左右半区，避免在 Banner 内形成嵌套卡片。
- 每个入口的数量在上、名称在下，组成纵向信息组；信息组在对应半区内水平、垂直居中，左右半区整块均为触控区域，并保留轻微按下反馈。
- Banner 下方只保留 `芯片识别说明` 一条扁平帮助入口，不再展示传统文化解读、记录或证书的重复入口。
- `芯片识别说明` 在根页面只展示单行标题，不展示辅助说明文字；整行仍可点击进入完整说明页。
- 芯片说明入口使用细分隔线，不使用独立「使用帮助」标题或外层卡片。
- 每个入口整行可点，保留右侧箭头和按下反馈；有效触控高度不小于 56px。

## 视觉系统

- 页面使用暖白底色，避免纯白与冷灰。
- 主要文字使用近黑，辅助文字使用中性灰；深绿只用于账号状态、核心入口图标和当前底部标签。
- 采用 18px 页面水平安全边距、细分隔线和明确的上下节奏，不使用渐变、发光、玻璃拟态、大阴影、嵌套卡片或深绿整块容器。
- 保留现有系统字体与图标库，确保与整个小程序一致。

## 交互与状态

- `微信授权登录` 继续使用共享授权状态，授权后就地切换为已登录展示。
- 未登录点击 `问帖记录` 时继续显示登录授权底部弹层，授权完成后进入真实历史列表。
- `本串证书` 与 `芯片识别说明` 保留现有跳转目标。
- 底部 `首页 / 商城 / 问帖 / 我的` 导航保持现状，`我的` 为当前激活项。
- 页面在 iPhone 与 Pixel 10 上均应在固定底部标签栏上方一屏完整展示，不产生横向溢出。

## 代码边界

- 修改 `src/prototype.css` 中 Profile 专属样式。

- 在 `AGENTS.md` 记录本次新的持久设计决策，其优先级高于 2026-08-24 的旧 Profile 方向。
- 不修改受保护移动运行时，不新增路由，不新增图片、语音、后端登录或数据持久化。

## 验收标准

- 页面不存在 `个人香事档案` 大标题、`记录与管理` 标题、`使用帮助` 标题或深绿双入口块。
- 账号状态与登录操作位于产品图 Banner 上，Banner 是第一视觉焦点，并与列表保持明确间距；授权前后结构稳定。
- 两个 Banner 数据入口和一个芯片说明入口的文案与跳转正确，不重复展示记录或证书行。
- 两个 Banner 数据入口背景透明、无外框、无圆角，仅保留中间分隔线；各自内容中心与对应半区中心的水平和垂直偏差不超过 2px。
- 三个功能入口与登录按钮满足移动端触控尺寸要求。
- iPhone 与 Pixel 10 均能在固定底部导航上方一屏展示完整内容。
- `npm run check:runtime`、相关 Playwright 测试和 `npm run build` 通过；真实渲染与视觉稿完成同视口对照，`design-qa.md` 最终为 `final result: passed`。
