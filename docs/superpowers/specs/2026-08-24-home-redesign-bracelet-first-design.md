# 首页重设计：手串即首页

## 目标

把现有首页从“品牌 Banner、手串资料、问帖入口依次堆叠”重构为一个以真实手串为视觉主角的微信小程序首页。用户打开后应在 2 秒内确认这是自己的沉香手串，并在首屏完成“为本串问一帖”。

本设计只重构首页，不改变“问帖”“我的”、证书与溯源、微信授权弹层和问帖 Agent 的既有职责与流程。

本规格在首页结构上取代 `2026-08-24-home-profile-dedup-design.md` 中“独立 Banner + 独立当前手串”的旧方案；“我的”去重与全局授权规则继续有效。

## 已确认方向

采用 B「手串即首页」。

一句话设计命题：通过一个合并品牌广告、手串身份与核验状态的产品主视觉，让已识别手串的用户在 2 秒内确认对象，并在首屏直接开始问帖；整体呈现真实、克制、有农垦来源感的日常沉香产品气质。

### 第一视觉焦点

首页顶部使用真实沉香手串照片作为唯一产品主视觉。该区域同时承担：

- 顶部图像广告位
- 广东农垦品牌来源
- 当前手串名称、编号、年份、产区和香韵
- 身份已核验状态

删除独立 Banner 与独立“当前手串”信息块，不再重复展示同一张手串图片。

### 第一操作入口

产品主视觉下方紧邻问帖主场：

- 业务标签：`AI传统文化解读`
- 主标题：`为这串沉香，问一件挂心事`
- 主按钮：`开始问帖`

主按钮是首页唯一实心深绿色操作。未登录点击后继续使用现有微信授权底部弹层；授权完成后直接进入问帖。

## 首页结构

从上到下固定为：

1. 沉浸式顶部：不显示“我的沉香”标题，只保留右上小程序胶囊；手串照片从设备屏幕顶边开始并铺到状态栏电量区域下方。
2. 手串产品主视觉：真实手串照片、广东农垦标识、核验状态与当前手串信息合并呈现。
3. 问帖主场：业务标签、主标题与唯一主按钮。
4. 来源入口：`来自农垦的时间 / 查看本串来处`，点击进入现有证书与溯源页。
5. 最近问帖：只展示最近一条标题与时间，点击时经过共享登录门槛并进入问帖。
6. 次级服务：证书与溯源、佩戴养护、沉香知识收成一条三等分文字快捷栏，位于底部 Tab 上方。
7. 底部 Tab：首页、问帖、我的，行为不变。

首页不新增轮播、指标、快捷宫格、问帖分类卡或营销模块。

## 构图与比例

- 设计基准：390 × 844；同步验证 iPhone 与 Pixel 10。
- 产品主视觉从设备屏幕顶边开始，覆盖状态栏与原导航栏区域，左右通铺至页面边缘，不使用外边距或圆角。
- 问帖、来源、历史和快捷服务使用 14–16px 左右安全边距。
- 产品主视觉总高约 302px，其中约 108–118px 承担状态栏与小程序胶囊安全区；安全区以下的有效产品内容高度仍约 194px。
- 手串照片占主视觉约 72%，底部使用约 28% 的纯色信息带承载身份信息；禁止渐变遮罩。
- 广东农垦标识位于胶囊安全区下方的照片左上，以小尺寸暖白纸签承载。
- 问帖主场与产品主视觉之间保持 18–20px 间距，主标题使用克制宋体点题，其余使用系统字体。
- 主按钮高度不小于 48px，确保 iPhone 和 Pixel 首屏完整可见。
- 首页全部内容必须在底部 Tab 上方一屏呈现，`MobileScroll` 不产生纵向滚动。
- 最近问帖和来源入口使用横线与字级分组，不增加独立卡片。

## 视觉系统

- 背景：延续现有米白纸张色。
- 主色：深松绿色，仅用于主按钮、已核验状态和必要强调。
- 辅助色：农垦暖棕，用于业务标签与来源信息。
- 图片：只使用现有真实手串图和广东农垦标识，不生成新的产品近似图。
- 容器：首页只保留一个通铺产品主视觉；问帖、来源、历史和服务直接落在统一页面背景上。
- 圆角：顶部产品主视觉不使用圆角；仅主问帖按钮保留小程序操作所需的中等圆角。
- 禁止：渐变、光晕、玻璃拟态、悬浮阴影、卡片嵌套、AI 头像、在线点、通用聊天气泡和重复产品图。

## 交互与状态

- 点击产品主视觉或“查看本串来处”：进入现有证书与溯源页。
- 点击“开始问帖”：已授权直接进入；未授权先打开现有微信授权底部弹层，授权后自动续接问帖。
- 点击最近问帖：复用同一全局授权状态，不创建独立登录状态。
- 点击底部“问帖”：行为保持一致，继续经过共享授权门槛。
- 所有可点击区域不小于 iOS 44px / Android 48px，并保留按下反馈。
- 页面滚动、状态栏、底部安全区和设备切换继续由现有移动运行时负责；首页仅把既有胶囊覆盖到沉浸式 Banner 上。

## 主动舍弃

- 舍弃独立品牌 Banner 与独立当前手串模块并列的结构。
- 舍弃首页首屏内完整展开年份、产区、香韵三列资料表。
- 舍弃让证书、养护、知识与问帖同等显眼的功能卡片，三项服务只保留一行文字快捷入口。
- 舍弃通过更多圆角、阴影或装饰建立“高级感”的做法。

## 验收标准

- 首页顶部只有一个手串产品主视觉，同一张手串图不在首屏重复出现。
- 手串产品主视觉从设备屏幕顶边起左右通铺，并延伸到状态栏电量区域下方，外层圆角为 0。
- 首页不显示“我的沉香”标题，右上小程序胶囊完整可见且不遮挡品牌标识。
- 产品主视觉同时可见广东农垦标识、手串名称、编号与核验状态。
- “开始问帖”是首屏唯一实心主按钮，在 iPhone 与 Pixel 底部 Tab 上方完整可见。
- 未授权不能直接进入问帖；授权后自动进入目标问帖流程。
- 点击产品主视觉和来源入口均能进入现有证书与溯源页。
- 最近问帖和次级服务使用分隔列表，不形成卡片墙。
- 首页在 iPhone 与 Pixel 上均无纵向滚动，所有首页内容在固定底部 Tab 上方一屏完成。
- 首页无渐变、光晕、玻璃拟态、产品图重复、文字截断或小于平台规范的触控目标。
- 至少完成两轮真实渲染复核，并与当前首页截图并排比较后再交付。

## 非本次范围

- 不接入真实微信登录、用户后端或账户绑定。
- 不迁移为原生 WXML/WXSS。
- 不新增轮播广告后台、内容管理后台或多手串切换逻辑。
- 不改变问帖 Agent 的追问、回答与免责声明逻辑。
