# 客户补充反馈：首页与藏品服务扩展

## 目标

在现有微信小程序需求原型中落实客户《广垦沉香AI 小程序版面补充建议》与已确认范围：保留参考图的首页视觉语言，把首页从一屏式结构扩展为可纵向浏览的品牌与藏品服务首页；新增认种档案、产业园内容、多藏品切换和电子证书下载；底部增加“商城”入口，但商城本期只做占位，不建设商城页面、商品详情、购物车、订单或支付流程。

本规格是 2026-08-28 的最新用户决策。与此前“首页必须一屏展示”“首页不展示独立农垦故事入口”“底部仅三个 Tab”等历史设计冲突时，以本规格为准。既有 AI 问帖、微信授权、问帖记录、证书溯源、养护、沉香知识和“我的”页面职责继续保留。

## 已确认范围

### 本期完成

- 首页顶部继续采用已选参考图的广东农垦 Logo、东方园林背景、人物持串插画和小程序胶囊构图。
- AI 问帖卡保持原有视觉结构，更新为香道静心表达。
- 首页增加“广垦沉香甄选”展示模块，展示四个业务方向。
- “我的藏品”支持手串与认种树档案横向切换。
- 手串与认种树均提供档案查看和演示版电子证书下载。
- 首页服务入口增加“认种我的沉香树”。
- 增加认种档案页面、产业园页面和藏品档案页面。
- 增加产业园图文轮播与可操作的视频展示位。
- 首页增加产业园信任背书、沉香小知识和版权信息。
- 底部导航调整为：首页、商城、问帖、我的。
- 保持现有授权连续性、AI 对话、历史问帖和帮助页面可用。

### 本期不做

- 商城首页、商品列表、商品详情、购物车、收货地址、订单、支付和真实交易。
- 真实后端、真实用户数据、真实微信登录、真实藏品绑定和真实证书服务。
- 原生 WXML/WXSS 迁移。
- 真实视频流、真实产业园素材后台和内容管理后台。
- 多用户、多账号、多设备同步。

## 产品与视觉方向

### 用户与核心任务

目标用户是购买、持有或准备了解广垦沉香产品的消费者。首页需要同时满足四项任务：确认品牌与产品、进入 AI 香道文化交流、管理个人藏品、了解广垦产业来源。

### 视觉原则

- 以用户给定参考图为视觉真源：米白纸张、深松绿色、暖棕木色、东方园林留白、人物持串插画、适度圆角和轻量阴影。
- 顶部品牌主视觉保持参考图的构图与比例，不改成真实手串大图或另一套品牌 Banner。
- 大标题允许使用克制宋体，其余信息和操作使用小程序系统字体。
- 页面层级依靠留白、分隔线和少量纸张卡片建立，不扩散为等权卡片墙。
- 所有可点击区域满足至少 44×44px 的触控尺寸，并提供按下或状态反馈。
- 首页允许纵向滚动；固定底部 Tab 不遮挡最后一项内容和版权信息。

## 信息架构

### 根级导航

根级 Tab 固定为四项：

1. 首页：品牌、AI 入口、业务展示、藏品、服务、产业园和知识内容。
2. 商城：仅作为本期占位入口；点击后显示“商城即将上线，敬请期待”的轻提示，不切换到空白页面。
3. 问帖：继续使用现有共享授权门槛，授权后进入 AI 对话。
4. 我的：继续承载授权状态、问帖记录、当前证书与帮助。

商城 Tab 仍需满足可点击和状态反馈要求，但不能表现为已建成的真实商城，也不能保留选中态造成用户误解。

### 首页顺序

首页从上到下为：

1. 顶部品牌主视觉。
2. AI 问帖卡。
3. 广垦沉香甄选。
4. 我的藏品。
5. 四项藏品服务。
6. 广垦沉香·源头产业园。
7. 沉香小知识。
8. 版权信息。

## 首页组件设计

### 1. 顶部品牌主视觉

- 显示广东农垦 Logo。
- 显示标题“广垦沉香 沉香手串”。
- 保留参考图中的东方园林背景、人物持串插画与小程序胶囊安全区。
- 该区域负责品牌建立，不承载证书、档案或购买操作。

### 2. AI 问帖卡

- 业务标签继续保留：`AI 传统文化解读`。
- 主标题：`以香静心，聊聊心中挂心事`。
- 副标题：`借沉香感悟心绪，AI香道文化解读`。
- 按钮：`开始问帖`。
- 按钮继续使用现有授权门槛：未授权先打开底部授权弹层，授权后自动进入原目标问帖。
- AI 页面现有追问、回答结构和免责声明不变。

### 3. 广垦沉香甄选

- 标题：`广垦沉香甄选`。
- 四个展示入口：`手串收藏`、`香道礼盒`、`企业定制`、`沉香树认种`。
- 模块底部显示 `进入商城`。
- 本期所有甄选入口与“进入商城”均只触发“商城即将上线，敬请期待”的轻提示，不进入新页面。
- 四项入口用于展示未来业务版图，不能使用价格、购物车、销量或“立即购买”等已交易化表达。

### 4. 我的藏品

- 标题：`我的藏品`，右侧保留 `查看档案`。
- 使用现有移动运行时的 `Carousel` 实现横向切换，不自行创建原生横向滚动。
- 至少提供两项本地演示数据：
  - 海南琼南沉香手串：档案编号 `CX-2018-072`、材质 `海南沉香`、规格 `18mm · 16颗`、认证状态。
  - 琼南一号认种沉香树：认种编号 `TR-2026-018`、基地 `琼南沉香产业园`、树龄与当前生长状态。
- 当前藏品卡展示对应缩略图、认证状态、核心资料、查看档案和导出电子证书。
- 横滑后，档案按钮和证书按钮必须跟随当前藏品，不允许始终打开第一项数据。

### 5. 四项服务

以同一组服务入口呈现：

- 证书与溯源：进入现有证书页。
- 佩戴养护：进入现有养护页。
- 沉香知识：进入现有知识页。
- 认种我的沉香树：进入认种档案页。

每个服务入口的完整格子均可点击。四项在窄屏上应保持可读和可触，不以压缩文字到过小字号换取单行展示；允许采用 2×2 布局。

### 6. 产业园背书

- 标题：`广垦沉香·源头产业园`。
- 正文：`广东农垦国资国企｜万亩沉香种植基地｜标准化无尘加工车间，全链路品控`。
- 按钮：`走进产业园`。
- 点击进入产业园页面。

### 7. 沉香小知识

- 首页展示两条文章摘要：真假辨别、日常保养。
- 文章行包含缩略图、标题、摘要和箭头。
- 点击真假辨别进入对应知识正文；点击日常保养可复用现有养护页面或打开对应知识正文，但需有明确页面结果。

### 8. 版权信息

文案固定为：`广东农垦曙光农场有限公司 © 广垦沉香`。

## 二级页面

### 藏品档案

- 页面标题随当前藏品变化。
- 手串档案展示编号、材质、规格、核验状态、来源摘要和证书入口。
- 认种树档案展示认种编号、基地、树龄、认种日期、当前状态和成长记录入口。
- 返回时回到首页原有滚动与藏品选择状态；原型至少不得错误切换为另一藏品。

### 认种档案

- 显示树木名称、认种编号、认种人演示名、基地位置、认种日期、树龄和当前状态。
- 显示成长时间线：认种登记、养护建档、最近巡检、下一次回访。
- 显示电子认种证书入口。
- 显示“前往认种”业务入口，但本期只触发商城即将上线提示。

### 产业园

- 使用 `Carousel` 展示基地、育苗、加工车间和品控四类图文内容。
- 页面提供一个视频展示位，具有封面、播放按钮、播放中/暂停状态和时长提示；本期不加载真实远程视频。
- 说明内容聚焦国企来源、种植基地、标准化加工和全链路品控。
- 明确区分品牌产业故事与单件手串的证书溯源，不混用核验结论。

### 知识文章

- 至少补齐“如何快速辨别沉香手串的真假”正文页。
- 日常保养可继续复用现有养护页，入口文案与目标页面一致。

## 电子证书下载

- 原型提供两份本地演示 PDF：手串一物一证档案、沉香树电子认种证书。
- PDF 文件存放于应用静态资源目录，通过语义化下载链接触发浏览器下载。
- 下载前显示当前证书名称；触发下载后显示成功反馈。
- 若浏览器阻止下载或文件不可访问，显示明确失败提示和重试入口。
- PDF 明确标注“需求原型演示文件”，避免被误认为正式签发证书。

## 状态与数据流

- 使用本地常量提供藏品、产业园轮播和知识文章演示数据。
- 当前藏品选择属于首页局部状态；藏品 ID 传递给档案与证书入口。
- 微信授权继续使用现有共享授权上下文，不能为新入口创建独立登录状态。
- 商城提示、证书下载结果等短暂反馈使用轻量提示层，不创建新的根页面。
- 页面切换继续通过现有 `FlowStack`；横向内容继续通过现有 `Carousel`；输入继续通过受保护移动运行时组件。
- 返回、打开弹层或切换页面前继续遵守现有键盘收起规则。

## 错误与边界处理

- 商城占位：点击始终有反馈，不进入空白页，不改变当前根 Tab。
- PDF 缺失：显示下载失败和重试，不静默失败。
- 图片缺失：保留稳定容器和文字，不造成布局坍塌。
- 轮播无素材：显示单个说明态，仍可返回。
- 多藏品切换：快速横滑或点击后只能打开当前选中藏品的档案。
- iPhone 与 Pixel 底部安全区必须分别正确处理，最后一项内容可滚动到固定 Tab 上方。

## 代码边界

- 应用 UI 仅修改 `src/Prototype.tsx` 与 `src/prototype.css`。
- 相关行为测试修改 `tests/prototype-h5.spec.ts`。
- 新增图片和 PDF 放在 `public/assets/` 下的任务专用目录。
- 不修改受保护的 `src/mobile/`、`src/App.tsx`、`src/styles.css`、设备资源、Vite 配置和 Worker，除非后续发现与本规格直接相关且用户另行授权。
- 项目当前不是 Git 工作树，不初始化 Git；以设计文档、测试、构建和渲染产物作为变更检查点。

## 验收标准

- 首页视觉明显保持用户参考图的品牌主视觉、色彩、排版与卡片节奏。
- 首页可纵向滚动，固定底部 Tab 不遮挡版权信息。
- 底部完整显示首页、商城、问帖、我的四项；商城点击只显示即将上线提示。
- AI 文案更新正确，开始问帖与授权续接行为不回退。
- 广垦沉香甄选四项业务可见，且均不会进入未建设的商城页面。
- 我的藏品可在手串与认种树之间横向切换，档案和证书入口跟随当前藏品。
- 两份演示 PDF 均能由对应入口触发下载，并带有原型演示标识。
- 证书、养护、知识、认种树四项服务均可从完整触控区域进入正确页面。
- 认种档案包含完整元数据、成长时间线和证书下载。
- 产业园包含四类图文轮播及可操作的视频展示状态。
- 两条沉香小知识均有明确页面结果。
- 现有问帖、问帖记录、证书溯源、“我的”授权和帮助页继续可用。
- `npm run check:runtime`、TypeScript 构建和相关 Playwright 测试通过。
- iPhone 与 Pixel 至少各完成首页、藏品切换、认种档案、产业园和 PDF 下载入口的真实渲染检查，无文字截断、遮挡、错误安全区或小于规范的触控目标。
