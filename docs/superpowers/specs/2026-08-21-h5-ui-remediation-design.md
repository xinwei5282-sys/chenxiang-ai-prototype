# AI 手串 H5 UI 整改设计

## 目标

将现有 AI 手串原型明确为“消费者扫码后直接打开的移动端 H5”，修复视觉走查中的 P0/P1 问题，同时保持已确认的 B 方案——数字身份、可信凭证、当代档案感——不改成原生 App，也不重做视觉方向。

## 范围

- 首页：数字身份、产品信息、证书溯源与 AI 增值服务入口。
- H5 内页：证书与溯源、AI 传统文化解读、佩戴养护、AI 沉香知识。
- H5 弹层：香文化顾问提问与提交成功状态。
- 设备：iPhone 与 Pixel 10 原型预览。

## 交互设计

1. 所有 H5 页面跳转前统一释放当前焦点并收起模拟键盘，再执行 `FlowStack` 跳转。
2. 详情页打开后，焦点落在返回按钮，页面从顶部开始，不继承首页按钮的焦点或滚动位置。
3. AI 顾问弹层刚打开时不主动聚焦输入框，因此不自动出现键盘。
4. 用户主动聚焦输入框后才显示键盘；提交、关闭和返回首页时先释放焦点并收起键盘。
5. 详情页使用 H5 固定顶栏，内容始终从状态栏/安全区下方开始。

## 视觉设计

- 延续深绿、米白、金棕配色和宋体档案语气。
- 不改变首页大图、数字身份标题和证书主入口的既有构图。
- 放大核验说明、证书元数据、正文和辅助标签，提高浅色文字对比度。
- 入口层级明确为：证书溯源（主）→ AI 传统文化解读（次主）→ 佩戴养护 / AI 沉香知识 / 香文化顾问（辅助）。
- 品牌栏压缩横向竞争，保证“广垦沉香”和“数字藏品档案”在真实手机尺寸下可读。

## 可访问性

- 路由切换后不保留上一页按钮焦点。
- 图标按钮维持至少 44×44px 触控区，并补充可见焦点样式。
- 小字号正文按真实手机尺寸提高到可阅读水平；弱化信息仍保持足够色差。
- 本次不修改受保护的 `FlowStack` 运行时，隐藏历史场景的 `inert` / `aria-hidden` 行为列为运行时后续专项。

## 验收标准

- 证书、文化解读、养护和知识页面打开时键盘为关闭状态。
- 详情页顶栏和首个标题不进入状态栏、灵动岛或摄像头区域。
- AI 顾问弹层打开时键盘关闭；输入框聚焦时打开；提交成功后关闭，成功按钮完整可见。
- iPhone 与 Pixel 10 首页无异常键盘，核心入口完整显示。
- `npm run check:runtime`、相关 Playwright 用例、`npm run build` 与 `npm run test:sites` 通过。
