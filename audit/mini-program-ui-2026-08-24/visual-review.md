# 小程序 UI 视觉复核

## 视觉真源

- 已选方向：随身香事
- 对比图：`reference-selected-c.png`
- 复核设备：iPhone、Pixel 10
- 复核状态：首页、我的、问帖初始、问帖结果

## 第一轮

与已选方向并排检查后：

- 首页的业务顺序、绿色主操作、最近问帖与三栏 Tab 已对齐视觉真源。
- 产品实图比例、正文密度和克制的米白/深绿配色成立，没有渐变、发光、头像或聊天气泡。
- iPhone 与 Pixel 的根页面导航未预留系统状态栏高度，导致标题位于刘海/挖孔区域；手串卡片的顶部身份行也被系统状态栏遮挡。
- 问帖页使用 `FlowScreen.header`，状态栏、标题、返回键和胶囊位置正确。
- 问帖结果保持连续记录结构，结论与行动建议未再嵌套成多层卡片；输入栏能避开 iPhone Home Indicator。

## 第一轮修正

- 将首页和“我的”的小程序导航迁入 `FlowScreen.header`。
- 由受保护运行时统一注入 iPhone / Pixel 顶部安全区，不再在业务 CSS 中估算状态栏。
- 根页面内容从安全导航下方开始，保留固定底部 Tab 与独立滚动内容。

## 第二轮验收项

- 首页标题、胶囊、当前手串标题与核验状态完整可见。
- Pixel 挖孔不覆盖页面标题，Android 导航栏不覆盖底部 Tab。
- iPhone / Pixel 的首屏主操作均在底部 Tab 上方。
- 我的页没有返回按钮，首页/我的以根 Tab 方式切换。
- 问帖页不显示根 Tab，输入栏与最新回复互不遮挡。

## 第二轮结论

- iPhone 首页已完整显示“我的沉香”、小程序胶囊、当前手串与核验状态；首屏层级与视觉真源一致。
- Pixel 首页标题位于挖孔下方，小程序胶囊与系统状态图标无重叠；底部 Tab 位于 Android 导航栏上方。
- 首页与“我的”页面的产品图片比例、文字密度、圆角和分隔线保持一致，没有恢复档案册式装饰。
- iPhone / Pixel 问帖页均保持独立固定标题栏，没有根 Tab；输入栏分别避开 Home Indicator 与 Android 导航栏。
- 第二轮未发现文字裁切、内容越界、触控目标过小或固定层互相遮挡，视觉复核通过。
