# 琼南沉香小程序原型：全局 UI / UX 走查

日期：2026-08-24  
范围：首页、微信授权、AI 问事、我的、问帖记录入口、证书与溯源、佩戴养护、沉香知识、农垦故事，以及 iPhone / Pixel 10 适配。  
方式：真实渲染截图、关键入口点击验证、界面代码与触控尺寸复核。此次只审计，不修改原型。

## 总体结论

当前原型已经形成清晰的品牌基调：暖纸色、深绿色、宋体标题、产品照片和原生小程序框架基本统一；首页、授权、证书页和农垦故事页已接近可演示水平。

当前最需要处理的不是继续“加设计”，而是补齐入口语义与内容完整度：`问帖记录` 实际进入新问帖，`我的手串` 实际进入证书页；佩戴养护和沉香知识内容明显偏薄；部分 9.5–11px 灰色文字对比度不足。

## 优点

- 首页只有一个主要动作“开始问帖”，证书、养护、知识降为明确的二级入口，信息层级正确。
- 微信授权使用手机内底部弹层，背景上下文仍可见，不再像独立登录页。
- AI 问事没有头像、在线点和结果卡堆叠，已从模板化 AI 页面转为普通聊天体验。
- 证书页和农垦故事页都建立了稳定的标题、正文、分割线和编号节奏。
- iPhone 与 Pixel 的状态栏、胶囊、底部安全区和输入框位置没有明显冲突。

## 修改建议

### P0：先修入口承诺与实际去向

1. **恢复真正的“问帖记录”流程。**
   - `问帖记录` → 记录列表（至少展示“新的合作是否适合推进？ / 三天前”）。
   - 点击记录 → 只读对话详情，底部提供“继续追问”。
   - 首页 CTA 和底部“问帖”才负责开启新对话。
   - 若暂时不做记录页，应先把入口改名为“继续问帖”，避免错误承诺。

2. **统一“我的手串”的名称与去向。**
   - 若仍直接进入当前证书页，改名为“本串证书”。
   - 若保留“我的手串”，应进入手串列表 / 管理页，再进入证书详情。

### P1：补内容完整度和可读性

3. **把农垦故事页的内容节奏复用到养护和知识页。**
   - 养护页：复用现有手串 3D 素材作为小型题图，补一条“常见误区 / 收纳提醒”，让页面形成完整收尾。
   - 知识页：保留农垦故事入口，再增加“沉香如何形成、怎样闻香、常见产区”三个轻量目录行；无需先扩建复杂新页面，可先做可展开内容。

4. **修正 AI 问事的免责声明位置。**
   - 不要让免责声明始终跟在最新消息后移动。
   - 推荐固定在输入框上方，或仅在首条 Agent 消息下展示一次。
   - 最终回答中的“判断 / 提醒 / 建议”只需加粗或变为深绿色标签文字，不要重新套结果卡。

5. **缩短授权弹层。**
   - “登录后开始问帖”和“先完成微信授权”表达重复，保留一个标题即可。
   - 主按钮可改为“微信授权并继续”，适用于首页、问帖 Tab 和记录入口。
   - 原型说明至少提升到 12px，并提高灰色对比度。

6. **处理小字和低对比度。**
   - 首页元数据、个人档案副文案、免责声明与原型说明目前大量使用 9.5–11px。
   - 实际色值中：`#999b94` 在 `#f7f6f1` 上约为 `2.60:1`，`#a0a29b` 在 `#fffefa` 上约为 `2.56:1`，不适合普通小字号正文。
   - 建议普通辅助文字不低于 12px，并把关键辅助色压深至接近 `#73776f`；正文尽量保持 14–15px。

7. **Pixel 端使用 48px 触控下限。**
   - 快捷问题、发送按钮、微信登录按钮当前多为 44px，高度符合 iOS 下限，但 Pixel 建议提升到 48px。
   - 可按设备变量调整，不必改变 iPhone 的整体密度。

8. **修正“使用帮助”的交互暗示。**
   - “芯片识别说明”“关于传统文化解读”现在像可点击列表，但实际是静态 `div`。
   - 推荐改为可点击行并增加箭头，进入轻量说明页 / 底部弹层；若不打算交互，则弱化图标和整行入口感。

### P2：视觉精修

9. **优化 Pixel 首页纵向比例。**
   - 不增加新模块，按更高屏幕适度增加 Banner、高亮问帖卡和三项服务条的高度，让整体比例随视口增长。
   - 保持问帖卡与服务条相邻，避免重新拉出过大间隔。

10. **处理首页云纹装饰。**
    - 当前云纹看起来像低对比度浅色贴片，边缘略虚。
    - 换成更干净的透明素材或直接删除；不要用更复杂的光效补救。

11. **保证状态栏在各种图片裁切下可读。**
    - Hero 继续铺到状态栏区域，但在顶部安全区增加极轻的半透明浅色保护层，避免黑色系统图标落到深色珠子上。

## 无障碍风险与验证边界

- 已确认：部分辅助文字对比度和字号偏低；Pixel 上部分触控目标为 44px；两段“使用帮助”只有视觉入口感，没有按钮语义。
- 已确认：主要按钮和导航具有可见文字或 `aria-label`，聊天输入和发送按钮有清晰标签。
- 截图不能证明完整的读屏顺序、动态字体缩放、真实微信小程序焦点行为、弱网与错误状态，也不能据此宣称完整 WCAG 合规；这些需在原生小程序阶段继续验证。
