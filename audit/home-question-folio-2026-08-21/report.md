# 首页「问帖主场」视觉复核

## Design Direction

- 场景与用户：消费者通过 NFC 识别广垦沉香手串后进入的移动端首页。
- 一句话设计命题：通过「产品身份舞台 → 核验凭据 → 问帖题签 → 档案索引」让用户先认串、再问事。
- 第一视觉焦点：已核验的当前手串；第二视觉焦点为唯一主操作 `为本串问一帖`。
- 空间结构：压缩后的品牌产品舞台占首屏上部，凭据信息扁平化，问帖题签占据拇指易达区，其他功能降为细线档案索引。
- 主要视觉记忆点：深绿方形问帖标记与铜棕题签边线。
- 与参考图继承关系：保留深沉香绿品牌栏、暖纸底、产品大图、档案编号、宋体与横向细线。
- 主动舍弃：三列图标元数据、双列功能宫格、所有入口等权、通用 AI 卡片风格。

## 第一轮发现与第二轮修正

1. 问帖题签虽已进入首屏，但视觉强度不足：加大主标题，使用深绿方形操作标记，加强铜棕边界。
2. 证书入口仍带英文装饰：改为 `壹 / 身份档案`，与中文问帖体系统一。
3. Pixel 截图保留了设备选择器焦点框：验收截图前释放桌面预览焦点，不修改受保护运行时。

## Recommendation

- 推荐方案：当前第二轮「问帖主场」。
- 推荐理由：首页已不再是功能列表，问帖入口在面积、对比和位置上明显高于证书及其他入口，同时保留 NFC 数字身份叙事。
- 未继续扩大改动：没有新增模块、营销文案或虚构资产，避免破坏已选定的博物馆档案参考方向。
